# Tic Tac Toe - Java

A simple two-player Tic Tac Toe game developed using Java.

## Features

- Two-player gameplay
- X and O turns
- Win detection
- Draw detection
- Invalid move handling

## Technologies Used

- Java
- Arrays
- Loops
- Methods
- Conditional statements

## How to Run

Compile the program:

```bash
javac TicTacToe.java
